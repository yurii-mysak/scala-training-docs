## Key Interview Questions by Level

**Beginner**: What is referential transparency? Why does immutability matter for concurrency? Explain tail recursion.

**Intermediate**: How does the IO monad handle side effects? What is the State monad and when would you use it?

**Advanced**: Compare tagless final vs Free monad. How do you achieve concurrency in a purely functional way?
