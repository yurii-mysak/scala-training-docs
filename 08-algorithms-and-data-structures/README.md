## Key Interview Questions by Level

**Beginner**: What is the time complexity of insert/search in a hash map? When would you use a stack vs a queue? What is amortized O(1)?

**Intermediate**: Compare QuickSort vs MergeSort trade-offs. When is DFS preferred over BFS? How does memoization turn exponential into polynomial time?

**Advanced**: Explain Dijkstra's algorithm and when it fails. How would you solve a 2D DP problem? Describe a real-world scenario where hash collision resolution matters.
