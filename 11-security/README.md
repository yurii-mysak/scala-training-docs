## Key Interview Questions by Level

**Beginner**: How does OAuth 2.0 work? What is the difference between authentication and authorization? How do you prevent SQL injection?

**Intermediate**: Explain the difference between symmetric and asymmetric encryption. How does JWT work and what are its security risks? What is HMAC?

**Advanced**: How would you design a zero-trust security architecture? Walk through a penetration test methodology. How do you handle secret rotation in a distributed system?
