## Key Interview Questions by Level

**Beginner**: What is the testing pyramid? When do you write unit vs integration tests? Explain TDD.

**Intermediate**: When should you use a mock vs a stub? How do you test asynchronous code? What makes a good test?

**Advanced**: What is property-based testing and when is it more effective than example-based? How do you design a load test? What JMH pitfalls should you be aware of?
