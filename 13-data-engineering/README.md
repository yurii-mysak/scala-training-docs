## Key Interview Questions by Level

**Beginner**: What is the difference between a data lake and a data warehouse? When would you use ETL vs ELT?

**Intermediate**: What is Parquet and why is it preferred for analytics? How does Delta Lake provide ACID transactions on a data lake?

**Advanced**: Explain the Lakehouse architecture. What is the medallion architecture (bronze/silver/gold)? How would you design a migration from a data warehouse to a Lakehouse?
