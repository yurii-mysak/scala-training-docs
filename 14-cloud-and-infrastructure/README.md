## Key Interview Questions by Level

**Beginner**: What are the main cloud messaging services and how do they compare? When would you use SQS vs SNS?

**Intermediate**: What is Infrastructure as Code? How does Terraform manage state? What are the key AWS services you would use for a typical web application?

**Advanced**: How would you design a multi-region deployment on AWS? What are the trade-offs between serverless and container-based architectures?
